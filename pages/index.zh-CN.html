识别声音 · 写入文本

遥控器通过蓝牙传来声音，语音搭子解码后送入虚拟麦克风，同时发送对应的语音快捷键。识别、实时文字与文本修正由输入工具完成；语音搭子本身不运行识别模型。

查看设置与常见问题 ↗
  1. 01

    安装并打开

    从 Release 下载 PKG，打开 Applications 中的 Voice Input Buddy。

  2. 02

    完成环境检查

    按向导授权蓝牙、输入监控、辅助功能，确认麦克风驱动已检测到。

  3. 03

    连接与配置

    连接遥控器。在输入工具里选择 Voice Input Buddy 麦克风，配置语音快捷键。

  4. 04

    打开输入框，说话

    通过向导测试，再按住语音键说话、松开结束。点按型工具可调整触发方式。

兼容范围

先选设备，再选输入工具。

硬件设备

小米蓝牙遥控器 2 Pro

已在本地验证连接与按键，用户已确认音频正常。包含 RC001 / RC003 系列 ATVV 协议适配；其他型号和固件需要实际测试。

当前不提供 Apple Siri Remote、通用 USB 按钮或脚踏设备支持。Windows 属于后续计划。

输入工具

微信输入法豆包输入法TypelessVokieVoiceCursor其他工具

选择对应入口，通过虚拟麦克风和语音快捷键配置。VoiceCursor 与其他工具分别提供入口，使用通用快捷键流程。

工具必须支持所选麦克风与语音快捷键。不同版本请通过向导验证；配置入口不代表所有版本已验证。

本地桥接，清楚的边界

不保存录音，不收集文本历史。

语音搭子不采集使用统计，也不上传日志。输入工具是否联网识别，请查看该工具的设置。

安装驱动需要管理员授权，会短暂重启音频服务。当前 PKG 未经 Apple 公证，系统可能阻止安装；更新可能需要重新授权。
