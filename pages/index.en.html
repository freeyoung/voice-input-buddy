HOW IT WORKS

A bridge between your hardware
and your input tool.

①

Your remote

Microphone audio + buttons

→
②

Voice Input Buddy

Decode audio · Trigger shortcuts

→
③

Input method / dictation tool

Recognize speech · Enter text

Your remote sends audio over Bluetooth. Voice Input Buddy decodes it, routes it into a virtual microphone, and triggers the voice shortcut. Recognition, live text, and corrections come from the input tool; Buddy does not run a speech-recognition model.

GET STARTED

One installer.
Four steps to get ready.

The app and microphone driver install together.
No need for two separate downloads.

Setup and troubleshooting ↗
  1. 01

    Install and open

    Download the PKG from Releases and open Voice Input Buddy in Applications.

  2. 02

    Check the environment

    Follow the guide for Bluetooth, Input Monitoring, and Accessibility permissions. Check that the microphone driver is detected.

  3. 03

    Connect and configure

    Connect your remote. Select the Voice Input Buddy microphone in your input tool and configure its voice shortcut.

  4. 04

    Focus a text field. Speak.

    Test with the guide, then hold the voice button to talk and release to finish. Adjust the trigger for tools that use start/stop taps.

COMPATIBILITY

Your remote. Your input tool.

HARDWARE

Xiaomi Bluetooth Remote 2 Pro

Connection and buttons tested locally; audio confirmed by the user. Includes RC001 / RC003 ATVV protocol support. Other models and firmware need testing.

The four-device scope includes Xiaomi Bluetooth Remote 2 Pro, Chromecast Voice Remote (G9N9N), Google TV Streamer Voice Remote (GY3LE), and Apple Siri Remote. The latter three are planned; adapters and hardware validation are pending. Windows is planned.

INPUT TOOLS

WeTypeDoubaoTypelessVokieVoiceCursorOther tools

Choose a tool and configure the virtual microphone and voice shortcut. VoiceCursor has its own entry, using the same custom-shortcut setup as other tools.

Your tool must support the selected microphone and a voice shortcut. Verify your version with the guide; a setup entry does not mean all versions have been tested.

LOCAL BRIDGE. CLEAR BOUNDARIES.

No recording archive. No transcript history.

Buddy does not collect usage statistics or upload logs. Check your input tool’s settings for its own network and recognition behavior.

Driver installation requires administrator authorization and briefly restarts audio. The current PKG is not Apple-notarized and may be blocked by macOS; updates may require renewed permissions.
