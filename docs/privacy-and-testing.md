# 隐私边界与验证

本产品保留本地排错日志及设置，不采集使用统计、不捕获回眸文本、不归档语音、不上传日志。旧统计数据模型、记录 API、统计界面及兼容清理逻辑均已移除。识别工具是否上传语音及文本，应依据所选工具的设置和政策，本产品不能代表第三方承诺离线。

自动验证包括上游 ATVV 编码、解码、会话准入与蓝牙生命周期测试，以及本项目的功能边界检查。自动化通过不证明遥控器真机兼容、目标输入法成功识别或驱动安装通过。

真实验收需要：全新权限下完整走 wizard；遥控器按住与松开；断连释放快捷键；连接/休眠恢复；输入框焦点保持；虚拟麦克风收到音频；目标 IME 和 VoiceCursor 的开始、停止和最终输入；驱动安装与卸载；确认统计、回眸和上传入口不存在。

首次提交是源码迁入，不宣称已完成硬件测试、Windows 支持、正式签名公证或公开发布。
