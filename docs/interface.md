# macOS 界面与使用流程

主导航按日常使用顺序排列，权限与环境保留在设置之前：

1. **设备连接**：选择与连接遥控器、连接状态、重新连接；选择音频输出设备、增益和设备刷新。
2. **按键映射**：顶部用紧凑下拉框选择已记录的设备；电量与连接详情在设备连接页显示。普通硬件按键与动作、快捷键和常用语。语音设置入口跳转到输入法集成，不再滚动到按键页底部。
3. **输入法集成**：当前输入工具、语音快捷键和音频状态；豆包、微信输入法、Typeless、Vokie 与 VoiceCursor 与其他工具的配置向导入口；语音触发方式与按住／点按行为。
4. **权限与环境**：蓝牙、输入监控、辅助功能三项授权；虚拟麦克风驱动是否已加载；安装说明和设备刷新；隐私与数据处理说明。
5. **通用设置**：顶部显著的“重新运行设置向导”；语言、启动与图标显示、设置导入导出、诊断日志与版本信息。

输入法集成通过已有 wizard 配置并验证，不读取其他应用的私有配置，也不把检测到安装当作兼容验证。VoiceCursor 有独立入口，沿用通用工具的自定义快捷键流程，未新增专用适配器。重新选择输入工具不会清除音频设备、增益或普通按键映射。

## 常见问题的入口

- 系统设置开关已开、App 却认为未授权：在权限页核对状态。临时开发签名变化会使旧授权失效，需要添加当前 App 并重新授权。
- 安装驱动后没有麦克风：在权限页刷新设备；检查安装包是否为 0.1.1 或更新版本，确认 Core Audio 已重新加载驱动。
- 遥控器连不上或不识别按键：进入设备连接检查具体设备与连接状态；检查权限页输入监控授权。
- 有声音却无法输入：进入输入法集成，核对目标工具的麦克风、语音快捷键和按下／松开行为，再运行实际输入测试。
- 需要从头检查配置：通用设置顶部重新运行向导。该流程不清除现有硬件连接与普通按键配置。

菜单栏使用原创单色麦克风与硬件按钮轮廓，提供 1x／2x 资源；正在传输语音时改为实心。图标为 macOS 模板图像，颜色由系统适配浅色、深色及选中状态。图标脚本为 `scripts/generate-status-icons.swift`。

首次设置向导先检查权限，顶部逐项显示八个步骤：系统权限、准备设备、连接遥控器、驱动与音频路由、按键测试、输入工具、语音测试和完成。权限检查不依赖预先选择设备；驱动检测在第 4 步完成，首屏只检查三项系统权限。没有单独的欢迎步骤。首次使用默认跟随系统语言，第一步左下角可选择系统默认、中文或英文，选择持久保存。旧版停在欢迎页的用户会进入系统权限。

第 2 步用单选圆点表示当前设备选择；Apple Siri Remote 与其他蓝牙语音设备显示为“尚未支持”的禁用选项，不启动连接或修改配置。
